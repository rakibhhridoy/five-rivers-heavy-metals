## Extra phase scripts (added during reproducibility audit)

| Script | Purpose | Outputs |
|--------|---------|---------|
| `extra_kd_compute.py` | K_d = sediment/water, reproduces Table 2 byte-for-byte | `results/s_kd_values.csv`, `results/s_kd_summary.csv` |
| `extra_primary_indices.py` | Primary-data contamination indices on USEPA backgrounds (Table 1) | `results/s_primary_indices.csv`, `results/s_primary_indices_river.csv` |
| `extra_pca_source_id.py` | PCA + varimax on primary n=34 (§3.6 RC1/RC2/RC3) | `results/s_pca_loadings.csv`, `results/s_pca_explained_var.csv` |
| `extra_per_river_mk.py` | Per-river Mann–Kendall trends (§3.4 detail) | `results/s_per_river_mk.csv` |
| `extra_mc_primary_headline.py` | Monte Carlo headline (§3.7) on primary n=34 + source-paper Tr/background — reproduces Pb 60.68% | `results/s_mc_primary_headline.csv`, `results/s_mc_primary_headline_summary.csv` |
| `extra_health_risk.py` | HQ and ILCR for sediment + water under EPA and Bangladesh-specific parameters (§3.7, S8.1–S8.3) | `results/s_hq_ilcr_sediment.csv`, `results/s_hq_ilcr_water.csv`, `results/s_hq_ilcr_sensitivity.csv` |
| `extra_dl_architectures.py` | All 5 DL architectures (S3.1–S3.5) as an importable library | (library; imported by `extra_lime_explanations.py`) |
| `extra_lime_explanations.py` | LIME local explanations, regenerates Fig 9 (S3.8) — needs TensorFlow | `results/s_lime_explanations.csv`, `figures/Fig9_lime_explanations.png` |
| `src/gis/calculate_spectral_indices.py` | 11 spectral indices from Sentinel-2/Landsat bands (§5) — needs rasterio + Zenodo rasters | index GeoTIFFs (to user-specified `--out`) |

See `src/gis/README_GIS.md` for the full LULC / change-detection workflow (Zenodo-raster-dependent).
